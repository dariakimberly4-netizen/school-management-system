# School Management System

A responsive GitHub Pages-ready school management demo.

## Demo login
- Username: `admin`
- Password: `school123`

## Included workspaces
Students, Teachers, Enrollment, Classes & Sections, Attendance, Schedules, Grades, Assignments, Accounting, Parents, Announcements, Documents, Inventory, Reports, Audit History, and Settings.

Records added in the browser are stored with localStorage.

> This is a front-end demo. For production use, connect authenticated accounts and a secure database backend.
